Импорт исходных глав

Три шага: файл → сопоставление → проверка и запись. Перевод Gemini здесь не запускается.

Собрать книгу с сайта

Укажите публичную страницу книги, проверьте оглавление и выберите главы. Перед записью в библиотеку остаётся обычный этап подтверждения.

Быстрый импорт — до 20 глав; для диапазона до 2000 глав используйте отдельный фоновый сбор с контрольными точками. Недоступные главы не принимаются за прочитанные.
