Оригинал и перевод

Исходник доступен для чтения. Редактируемый русский текст принимается отдельной ревизией только после подтверждения модератора.

Выберите книгу и главу. Доступные главы загрузятся с сервера.

Исходник — Принятая редакция — Черновик — Черновик основан на старой ревизии Принятый перевод устарел относительно исходника

Оригинал (CN / исходный язык)

Полный RAW. Ничего не исправляем и не переводим автоматически.


      

      

        

          
Перевод (RU)

          
Редактор переносит обычный текст в HTML-абзацы при принятии.

        

        
        

          Есть изменения, ещё не сохранённые на сервере. При переходе на другую главу они будут потеряны.
        

        
        
        
Черновик ещё не сохранён.

        
«Сохранить черновик» записывает рабочий текст отдельно от
          принятого перевода. «Принять редакцию» создаёт новую принятую ревизию.
          Чужие параллельные изменения приводят к 409, без перезаписи.
